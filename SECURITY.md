# Security reports

Report suspected vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/kellygold/paper-in/security/advisories/new). Do not put exploit details, credentials or personal documents in a public issue.

Include the Paper In and macOS versions, the affected feature, expected and actual behavior, and reproduction steps using fictional documents. Redact file paths, account details and logs. Never include an API key, password or provider login token.

Security fixes target the latest published beta. Older versions do not have a separate maintenance branch. This is a volunteer project; response times are not guaranteed.

For ordinary scanner errors, setup questions or feature requests, use [GitHub Issues](https://github.com/kellygold/paper-in/issues) and the [troubleshooting guide](docs/troubleshooting.md). Privacy and recovery behavior is documented [here](docs/privacy-and-recovery.md).
