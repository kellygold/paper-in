Paper In 0.4.0 beta · Apple Silicon (M-series) Macs · macOS 14 or later · Brother DS-940DW

This beta is ad-hoc signed, without Apple Developer ID signing or notarization. macOS will normally block the first open. Only allow it if you trust this download. No security settings need to be disabled globally.

Install the app

  1. Open the DMG and drag Paper In into Applications. Quit an older copy before replacing it; your drafts live separately in Application Support.
  2. Open Paper In from Applications. If macOS blocks it, open System Settings → Privacy & Security → Open Anyway after the first attempt. Confirm only if you trust the app. Read Apple's instructions. Managed Macs may not permit an exception.
  3. Put the DS-940DW in USB mode, connect it, and close other scanner apps. Choose the output folder in Paper In, then click Connect.
  4. Insert a page and press Scan or Space. Add more pages, review both sides, and Save PDF.

Optional AI filing

Scanning needs no account. For automatic names and folders, open AI filing… and choose a provider. Node and the provider runtimes are included in the DMG; you do not need to install Node separately.

Claude and Codex use the official runtime's existing login, where your account and provider terms allow it. Initial sign-in is through those providers' own tools. Or choose OpenAI / Anthropic API, enter a supported model and store your API key in Keychain. API billing is separate.

Keep in mind

USB support is focused on the DS-940DW. Wi-Fi, Auto paper, long receipts and blank-page detection are still being calibrated. Review faint text and creased receipts. Skipped originals can be restored before saving. PDFs do not yet have a searchable text layer.

AI filing sends extracted text, folder names and selected related excerpts to your provider. Page images stay local. Originals are retained; filing can be undone. Privacy and recovery.
